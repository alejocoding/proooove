Test de Validaciones de Vehículos

Este archivo permite probar las validaciones en tiempo real.

Instrucciones de Prueba:

  • Placa: Debe ser 3 letras + 3 números (ej: ABC123)
  • Año: Entre 1900 y año actual + 1
  • Modelo: 2-50 caracteres, letras, números, espacios, guiones
  • Kilometraje: Entre 0 y 999,999
  • Campos Select: Deben tener una opción seleccionada

Verificaciones:

  • ✅ Los campos se validan en tiempo real mientras escribes
  • ✅ Los bordes cambian de color (verde = válido, rojo = inválido)
  • ✅ Los mensajes de error aparecen/desaparecen
  • ✅ Los selects muestran validación visual
  • ✅ Las validaciones se limpian al abrir los modales
